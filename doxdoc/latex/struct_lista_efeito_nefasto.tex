\doxysubsection{Detailed Description}
Estrutura que representa o efeito nefasto e as suas coordenadas. 

Esta estrutura é utilizada para criar uma lista ligada dos efeitos nefastos, onde cada nodo contém as coordenadas do efeito (x, y) e um apontador para o próximo nodo.
