\doxysubsection{Detailed Description}
Estrutura que representa uma antena com coordenadas e frequência. 

Esta estrutura é utilizada para criar uma lista ligada de antenas, onde cada nodo contém as coordenadas da antena (x, y), a sua frequência e um apontador para o próximo nodo.
