Detailed Description

Representa uma interseção entre dois pares de antenas, cada par com uma frequência distinta.

Contém os quatro vértices envolvidos na interseção (dois para a frequência A e dois para a frequência B), bem como as coordenadas calculadas do ponto de interseção.
