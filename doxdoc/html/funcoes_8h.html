◆ CalcularEfeitoNefasto()

ListaEfeitoNefasto * CalcularEfeitoNefasto ( Antenas * lista)

Calcula e retorna os pontos com efeito nefasto entre antenas com a mesma frequência.

Para cada par de antenas com a mesma frequência, calcula dois pontos simétricos e adiciona à lista de efeitos nefastos, se forem válidos (x >= 1 e y >= 1).

Parameters
listaPonteiro para a lista de antenas.
Returns

Carrega as antenas do ficheiro (ex.: "mapaAntenas.txt") para uma lista ligada.
